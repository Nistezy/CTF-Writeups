# 🧠 OverTheWire Bandit – Jornada Completa e Aprendizados

## 🎯 Visão Geral
O OverTheWire Bandit é um wargame focado em fundamentos de Linux, segurança e raciocínio lógico aplicado à exploração controlada.

## 🚀 Objetivo da Jornada
- Desenvolver domínio em Linux CLI
- Entender permissões, processos e serviços
- Aplicar conceitos reais de segurança ofensiva

## 🧩 Estrutura dos Desafios
acesso limitado → exploração → descoberta → acesso ao próximo nível

## 🔍 Principais Conceitos Aprendidos
- Linux básico (ls, cat, find)
- Permissões e usuários
- Scripts e automação (cron)
- Networking (ssh, nc)
- Exploração de lógica

## 💣 Destaques Técnicos
- Escalada via cron jobs
- Brute force controlado
- Escape de shells restritos
- Git forensics (log, branches, tags)
- Validação remota com git push
- Bypass de uppercase shell ($0)

## 🧠 Mentalidade Desenvolvida
Entender o sistema → explorar lógica → obter acesso

## 🏁 Conclusão
Bandit consolida base sólida em Linux e segurança ofensiva.
